FAQ

Frequently Asked Questions

Can Now Pilot make unauthorized writes to our production records? +
No. Now Pilot enforces a zero-unapproved-writes contract. Every change is staged as an immutable proposal sealed with a cryptographic SHA-256 HMAC hash. Changes are applied only after an authorized user reviews the proposed diff and clicks Accept.
Which ServiceNow releases are supported? +
Now Pilot v1.5.0 is tested and verified on ServiceNow Vancouver, Washington DC, Xanadu, and Australia (Patch 7+). It runs in classic UI16 forms, list views, and inside Next Experience / Polaris iframes.
Can we connect our own private AI Gateway or local models? +
Yes. Now Pilot supports OmniRoute, Anthropic Claude, OpenAI, and any OpenAI-compatible API (including Grok, Ollama, vLLM, and LM Studio). You can route traffic through your own self-hosted gateway with automatic fallback.
How is Now Pilot installed into a ServiceNow instance? +
Now Pilot is distributed as two clean XML Update Sets: gmg_ai_agent_global.xml (UI Script) and gmg_ai_agent_scoped.xml (Scoped application with tables, ACLs, and Script Includes). Simply import, preview, and commit both sets.
